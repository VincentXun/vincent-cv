# 简历模板选择说明

## 结论

本次保留 **Harvard MCS 官方 Bullet-Point Resume Template** 的技术简历结构逻辑，同时因明确需要放头像，改用“**固定双列表头 + 单栏正文**”的中国研发岗投递版：左侧为姓名、岗位和联系方式，右侧是表格单元格内嵌的 3:4 证件照。头像不使用浮动对象或侧栏。

- 官方模板页：[Harvard College Bullet-Point Resume Template](https://careerservices.fas.harvard.edu/resources/bullet-point-resume-template/)
- 可编辑 Word 模板：[官方 `.docx` 文件](https://cdn-careerservices.fas.harvard.edu/wp-content/uploads/sites/161/2025/09/2025-template_bullet.docx)
- 技术简历写法参考：[Harvard SEAS Resume Guide](https://seas.harvard.edu/office-student-career-development/resources-undergraduate-students/resumes-portfolios)
- ATS 与排版检查参考：[MIT ATS-friendly resume guide](https://capd.mit.edu/resources/make-your-resume-ats-friendly/)
- 带头像布局参考：[ResumeKraft — Simple CV Template with Photo for Word](https://resumekraft.com/simple-cv-template-with-photo-for-word/)
- 另一个官方带照片模板参考：[Microsoft Word 现代照片简历](https://word.cloud.microsoft/create/zh-hans/resume-templates/?source=create_flow)

## 为什么适合这次投递

深圳具身智能公司的初筛更需要快速判断候选人是否具备“真实机器人 + 操作学习 + 视觉/传感 + 工程落地”能力。单栏项目符号格式能让招聘者先看到最相关的项目，ATS 也能稳定解析联系方式、技术关键词和经历；固定页眉则符合国内投递中附证件照的习惯，并避免跨软件打开时头像漂移。

建议顺序：

```text
姓名 / 联系方式 / 求职方向
教育背景
核心技术
精选具身智能项目
研发与实习经历
竞赛、奖项与成果
```

## 本版本的排版规则

- 一页 A4、正文单栏；页眉为 1×2 表格，正文建议 9–10 pt，页边距约 0.65–0.8 英寸。
- 头像固定在页眉右侧 3:4 相框中，和姓名/联系方式属于同一个表格，不使用页面锚定、环绕或浮动文本框。
- 不放性别、出生日期、户籍、技能进度条、图标或双栏侧边栏。
- 每个项目用 2–3 条“**动作 + 技术方法 + 可验证结果/场景**”的短句，避免职责清单式描述。
- 技术栈只写实际用过或能在面试中展开的内容；量化结果必须标注其边界（例如“仿真验收”，不能写成真机成功）。
- 投递时按岗位描述微调前两项项目和技能关键词；保留一份完整母版，再导出对应职位的 PDF/DOCX。

如果投递海外岗位或纯 ATS 网申，可继续使用无头像版本；深圳具身智能企业的简历附件则优先使用本次固定头像版本。
